# INFOTEL PERÚ: tienda online (hackatón)

Prototipo de tienda web de **artesanía y moda peruana**, hecho para una hackatón.

## Funciones
- Página de inicio con productos y categorías destacadas.
- Carrito de compras (`cart.html`).
- Proceso de pago (`checkout.html`).

## Stack
HTML · CSS · JavaScript · Vite · Tailwind CSS

## Cómo correrlo
```bash
cd project
npm install
npm run dev
```
